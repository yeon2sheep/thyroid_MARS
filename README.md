# Thyroid Cancer MARS Pipeline

## Goal

East Asian thyroid disease GWAS summary statistics
with ancestry-matched EAS LD reference.

## Main Pipeline

GWAS summary statistics
→ EAS genotype
→ Harmonization
→ Variant bin definition
→ Signed LD matrix
→ MARS
→ Fine-mapping
→ Functional annotation
